# Reusable launch lessons

1. An official game description can verify core mechanics but cannot verify a keyboard table or prove the absence of codes. Keep those evidence boundaries visible.
2. Follow the user's simplified domain flow: newly purchased Spaceship domains known never to have DNSSEC skip DS/DNSSEC work. Add CF Zone, obtain its exact NS, switch registrar NS, wait Active, then verify Pages/HTTPS/GSC/sitemap. Investigate DNSSEC only on an actual related error, activation anomaly, known previous DNSSEC/migration, or unknown state. This domain already has authoritative DS evidence, so preserve that real exception. Never proactively enable, disable or restore DNSSEC or block a genuinely unsigned launch on unnecessary operations.
3. Cloudflare token validity, resource reads and individual resource writes are different facts. Create only necessary target resources and verify the result.
4. Similarweb generic phrase matches can reflect a different intent. Geography paywalls and sparse coverage must not turn into invented US metrics.
5. Use AnvilWiki apply-template before authoring. Its demo contract tests assume resources that a real fork removes; scope production tests explicitly and preserve excluded upstream suites.
6. Check real browser behavior as well as link existence: the template's pathname normalizer originally modified fragment targets. Static link checks did not detect that interaction bug.
7. Verify the actual viewport width. The browser-level resize returned desktop dimensions; tab-scoped CDP confirmed 375px and zero document overflow.
8. Deploy Pages independently of domain migration. Keep the formal launch gate open until the requested host, DNS and HTTPS actually work.
9. A GitHub source association does not prove push builds work. Verify the exact new commit reaches Pages. A project-only secret deployment hook can connect successful CI to the source build without uploading broad provider credentials.
10. Create analytics only for the current site, then verify both consent branches, actual page_view network receipt and the correct property's Realtime report. A self-test is not organic traffic. Wrangler vars apply on Cloudflare; local Astro builds need the corresponding environment value.
11. A stale text snapshot can misrepresent a loaded analytics UI. Compare the rendered page before declaring a blocker; Escape can close an unresponsive embedded tag panel. Record unresolved browser cleanup separately from verified website deployment.
12. Pages _redirects supports paths, not domain-level source rules. Verify www behavior on the actual hostname. Use an available, documented Cloudflare platform redirect without expanding credential scope or adding Functions unnecessarily; retain the original path and query string and test HTTP as well as HTTPS.
13. When an actual signed-domain migration is approved, distinguish the registrar switch, registry DS removal, recursive DS caches, delegation, Zone Active, certificate status and public HTTP success. Different resolver pools can disagree after registry withdrawal. Keep the final public-DNS gate open until the observed validation failures clear; do not repeatedly mutate a correct NS/DS configuration.
